# Security Policy

## Supported versions

Security fixes are applied to the latest release and the `main` branch.

## Reporting a vulnerability

Do not disclose security vulnerabilities in a public issue. Submit a private
report through GitHub's **Security** tab using **Report a vulnerability**. If
private reporting is unavailable, open a minimal issue requesting a private
contact channel without including exploit details.

Include the affected version or commit, reproduction steps, expected impact,
and any suggested mitigation. Reports will be acknowledged after validation.
